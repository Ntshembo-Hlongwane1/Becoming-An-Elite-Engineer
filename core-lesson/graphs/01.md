# Graph Representations in C++

## Adjacency list/matric, edge list, compressed sparse row (CSR) for performance

### Ajacency List

An adjacency list is a space-efficient way to represent a graph, especially when dealing with sparse graphs. In this representation:

- **Structure:** Each vertex has a list (or vector) containing its adjacent vertices

- **Implementation:** In C++, this is typicall implmented using an array of vectors or list, where each index corresponds to a vertex, and the associated vector/list contains its neigbors.

**Advantages:**

- **Space Efficiency:** Requires O(V + E) space, where V is the number of vertices and E is the number of Edges.

- **Efficient Iteration:** Allows quick iteratioin over the neighbors of a vertex

**Disadvantages:** 

- **Edge Lookup:** Checking if an edge exists between two vertices can take O(d) time, where d is the degree of vertex.

- **Not Cache-Friendly:** Due to non-contigous memory allocation, it may suffer from poor cache.

**Example:**

```cpp
#include <iostream>
#include <vector>

class Graph {
    int V;
    std::vector<int>* adjList;

    public:
        Graph(int V) : V(V){
            adjList = new std::vector<int>[V];
        }

        void addEdge(int v, int w){
            adjList[v].push_back(w);
        };

        void printGraph(){
            for (int v = 0; v < V; ++v){
                std::cout << "\n Vertex " << v << ".";

                for (int x : adjList[v]){
                    std::cout << " -> " << x;
                }
                std::cout << std::endl;
            }
        }
}
```

### Edge List

An edge list is a simple representation where all edges are store in a list of pairs (or tuples):

- **Structure:** A list of pairs, each representing an edge between two vertices.

- **Implmentation:** In C++, this is implmented using `std::vector<std::pair<int, int>>` for an undirected graph

**Advantages:**

- **Simple Structure:** Easy to implement and understand

- **Space Efficient:** Requires O(E) space.

**Disadvantages:**

- **Inefficient Edge Lookup:** Checking if an edge exists takes O(E) time.

- **Inefficient Neighbor Lookup:** Finding all neighbors of a vertex requires O(E) time


**Exmaple:**

```cpp
#include <iostream>
#include <vector>
#include <utility>

class Graph {
    std::vector<std::pair<int, int>> edges;

    public:
        void addEdge(int u, int v){
            edges.push_back(std::make_pair(u, v));
        };

        void printEdges(){
            for (auto& edge : edges){
                std::cout << "(" << edge.first << ", " << edge.second << ")\n"
            }

            std::cout << std::endl;
        }
}
```
