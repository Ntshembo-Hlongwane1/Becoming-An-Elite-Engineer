## 1.1  Program Structure

Modern C++ programs can have various building blocks which can be quite complex depending on the program but looking at a simple program the sture is as follows:


Preprocessor Directives \
&emsp;&emsp;&emsp;&emsp;&emsp;        &uarr;

Namespace Declaration  
&emsp;&emsp;&emsp;&emsp;&emsp;        &uarr;

Function Declaration \
&emsp;&emsp;&emsp;&emsp;&emsp;        &uarr;

Statements and Expression \
&emsp;&emsp;&emsp;&emsp;&emsp;        &uarr;

Return Statement

```cpp
#include <iostream>

using namespace std

int main(){
    cout << "Hello World" << endl;

    return 0;
}
```

- **Preprocessor Directives:** Lines that start with '#' are preprocessor directives. The preprocess handles this lines before the compiler starts to translate the code into machine instructions.
> Most common directives are #include | #pragma once

- **Namespace:** C++ make use of namespaces to avoid naming conflicts, (I like to think of it as a package which has various capabilities). The ```using namespace std;``` statement allows access to this 'packages' cabilities without having to preving all the time with ```std::```

- **Functions:** For a C++ to run it requires a ```main``` function, while it can have many other functions the ```main``` serves as C++'s progra entry point. It must always return an integer to the OS to indicate the program's success or failure

- **Statments and Expressions:** This is the code that's one writes e.g ```std::cout << "Hello world"" << std::endl;```. An expression is evaluated to produces a result, such as ```return 0;```

### Including Libraries

- Libraries can be included by using the ```#include``` preprocessor directives. for example if I wanted to include the standard I/O lib I coudl ```#include <iostream> // Include the standard I/O lib```

#### How Libraries work in C++

Libraries in C++ can be categorized into 2 types:

**1. Standard Libaries:** These come with the C++ compiler. Including fundamental features like data structures (vector, list), algorithms (sort, find) and I/O (cin, cout)

**2. Third-Party Libraries:** These libraries are provided by developers to extend the functionality of C++

- When a lib is included the preprocessor copies the contents of libs header file into my program, this then gives me access to the functions, classes and other components defined within.

**N.B** Including a lib does not mean the entire lib is compiled into the program; only the specific functions or classes I need are linked into the final executable during compilation phase

--- 

### The main Function

The ```main``` function is the heart of every C++ program. This is where execution of a program begins and ends. Regardless of the size of the program the main function is always the entry point.

```cpp
int main(){
    // Code logic here
    return 0; // Exit program
}
```

**Return Type:**  The ```main``` function always returns an integer value to the OS. By convention a return a value of **0** indicates successful execution, while non-zero values indicates error or abonormal program termination.

**Function Body:** The body of the ```main``` contains actual code that will be executed when the program runs.

## 1.2 Variables and Basic Types

### **int (Integer Type)**
The ```int``` type represents whole numbers (without fractional components). It can be used to store both positive and negative numbers.

```cpp
int cars = 100;
```

- **Size and Range:** 
    - Typically an ```int``` occupies 4 bytes (32 bits) of memory
    > Though size can vary depending on the system arch

    - Most system an ```int``` ranges from **-2,147,483,648 to 2,147,483,64** for **32-bit integers**. On 64-bit systems, it may be able to store large range.

- **Signed and Unsigned:** 
    - By default, ```int``` is a **signed** type, meaning it can store both negative and positive values.

    - Given a case where I know that I will have only positive integers I can use ```unsigned int``` type. The ```unsigned``` version doubles the positive range of the type by eliminating the negative range.

```cpp
unsigned int num = 300;
```
- **Short and Long Integers:** Depending on the system requirement, I can use ```short``` for smaller integer ranges (typically 2 bytes) or ```long``` for larger ranges (typically 4 or 8 bytes). 

```cpp
short smallNumber = 100; // -32,768 to 32,767
long largeNumber = 100000L; // -2,147,483,648 to 2,147,483,647 (for 4 bytes)
```

### float (Floating-Point Type)

The ```float``` type is used to represent real numbers (i.e numbers that can have fractional part).

```cpp
float price = 9.99f;
```

- **Precision:** A float typically occupies 4 bytes (32 bits) an can represent 6-7 decimial numbers.

- **Suffixed Literal:** In C++ floating-point literals i.e for example 1.0 will be treated as a **double** (which occupies 8 bytes). To explicitly declare a **float** literal I must append **f** or **F** at the end

```cpp
float pi = 3.14159f;
```

**Scientific Notation:** Scientific notation can be expressed using for example ```1.5e3 = 1.5 * 10^3```

### char (Character Type)

The **char** type is used to store a single, such has letters or symbols. A **char** takes 1 byte of memory.

```cpp
char grade = 'A';
```

**Character Representation:** Charactersa re enclosed in single quotes. E.g. 'A'.  Internall C++ makes of character encodings such as ASCII or Unicode to map char to a numeric value.

**Extended ASCII and Unicode:** The **char** type in C++ typically is based on the ASCII encoding which support 128 characters (including letters, digits, and common punctuation). **C++11** introduced support for wide characters with ```wchar_t``` type which represents charactes from extended encodings like **Unicode**

```cpp
wchar_t wideChar = L'C'; // Represents the Euro symbol in Unicode
```

### bool (Boolean Type)

The **bool** type is used for representation of logical values: either **true** or **false**. 

**Memory usage:** A **bool** is typically store in 1 byte of memory, even though **1 bit** is required to represent **true** or **false**. System adds this padding due to memory alignment constraints.

**Logical Operations** C++ provides logical operations such as **&& (AND)**, **|| (OR)** and ! (NOT) to work with boolean values.

```cpp
bool isEven = (number % 2 == 0);
```

**Default Initialization:** **bool** values can explicity be initialized to **true** or **false**. But a boolean values can also be evaluated from other types like **int**.
> N.B In C++, any non-zero value is intepreted as **true**, and zero is interpreted as **false**

```cpp
bool isNonZero = (5);
```

### Variables and Constants

Variables are memory locations that store values, and constants are used to store values that remain unchanged through the programs lifecycle.

#### Declaring and Initializing Variables

A type and name is required in order to define a variable. A value on defining the variables cane be provided

**Example**
```cpp
int age = 30;
float weight = 45.2f;
char grade = 'D';
```

> Declaration Syntax: <data_type> <variable_name>;

**Initialization:** To initialize a variable at the time of defining I can us ```=``` to assign a default value

> E.g int age = 60;

> N.B **Default Initialization:** A variable that is not intialized on declaration will be indeterminate. Using an indeterminate variable may result in undefined behavior.

#### Constants

A **constant** is a variable that which that value does not change once it has be assigned.

**Example**
```cpp
const int MAX_SIZE = 100;
```

**Immutability:** A const variables once initialized cannot be modified, any attempt to modify a const variable will result in a **compile-time error**

> MAX_SIZE = 101; // This will result in an error because we had already initialized MAX_SIZE to 100

#### constexpr (Compile-Time Constants)

From **C+11**, ```constexpr``` allows definition of constants whose value can be evalualted in compilation time. 

**Example**
```cpp
constexpr int square(int x){
    return x * x;
}
```

**Compile-Time Eval:** ```constexpr``` ensure that the function or variable is evaluated during compilation. Use of the value is directlu subbed into the code during compilation.

> E.g int result = square(5) // Result will be computed at compile time

**Limitation:** Function marked as ```constexpr``` can only contain simple experssions, and cannot have side effects i.e modifying any variables

#### The const VS constexpr Debate

**const:** This is used when I have value whose is fixed and should not be and I do not intended to change during runtime.

**constexpr:** Gurantee compile-time eval.

**Golden Rule:** If the function doesn't absolutely need something from the outside world (like ```std::cin```, files, system time), just add constexpr to it. Let the compiler yell at you if you're wrong.

> In modern C++20 constexpr function can even use std::vector, std::string and dynamic allocation. The only guaranteed "NO" signal when not to use is when you have I/O or runtime polymorphism (dynamic_cast or virtyal calls that aren't resolved at compile time).

### Working with Strings (std::string)

Strings are used to store sequence of characters, unlike char which holds a single character.

#### Declaring and Initializing Strings

To work with string, I must include the ```<string>``` header file.

```cpp
#include <string>

std::string greeting = "Hellow World"; 
```

**String Initialization:** Strings can be initialized using string literals or by creating an empty ```std::string``` object.

```cpp
std::string name = "Shane"; // Direct initialization from a string literal
std::string emptyString; // Empty string initialization
```

**Concatenating Strings:** I can concatenate multiple string using the **+** operator

```cpp
std::string firstName = "John";
std::string lastName = "Snow";
std::string fullName = firstName + " " + lastName; 
```

#### String Operations

**Accessing Characters:** Individual characters of a string can be accessed using the ```[]``` operator or the ```at()``` method.

> The at() method is safer because it throws an exception if the index is out of bounds.

**Example**
```cpp
char firstLetter = greeting[0];
char secondLetter = greeting.at(1);
```

**String Length:** To find the numbers of characters in a string, I can use the ```length() or size()``` method.

```cpp
std::cout << "The string length is: " << greeting.length() << std::endl; 
```
**Modifying Strings:** Strings can be modified by appending, insertin or replacing characters or substrings.

```cpp
greeting += " How are you?";
```

#### C-Style Strings VS std::string

C-style string are arrays of characters terminated by a null character (\0).

```cpp
char cstr[] = "Hellow, C!"
```

## Conditional Statements and Control Flow

Control flow mechanism enables programs to be dynamic, repeat actions and manage different states.


### Conditional Statements: if, else, switch

Conditional statements allow for program to select or execute specific code based on the condition being true or false.

#### The 'if' Statement

The ```if``` statement evaluates a conditions and executes a block of code if the condition evals to true.

```cpp
int number = 7;
if (number > 5){
    std::cout << "Number is greater than 5\n";
};
```
**Syntax**
```cpp
if (condition){
    //code to exec if conddition evals to true
}
```

**Condition:** In C++ any expression that resolves to a boolean value can be used as a condition.

- Comparions operators: ==, !=, >, <, >=, <=
- Logical operators: && (AND), || (OR), ! (NOT)
- Any non-zero value is treated as true, and zero is treated as false

#### The 'else' Statement

The **else** statement allows to specify a fall back when the **if** condition was not met.

```cpp
int age = 16;
if (age >= 18){
    std::cout << "You are an adult.\n";
}else{
    std::cout << "You are a minor.\n";
}
```

**Syntax**
```cpp
if (condition){
    // code if condtion is true
}else{
    // code if conditon is false
}
```

#### The 'else if' statement

The **else if** statement allows us to chain multiple conditions that will be sequentially checked 

```cpp
int marks = 85;
if (marks >= 90){
    std::cout << "Grade: A\n";
}else if (marks ?= 80){
    std::cout << "Grade: B\n";
}else if (marks >= 70){
    std::cout << "Grade: C\n";
}else{
    std::cout << "Grade: D\n";
}
```

### The switch Statement

The **switch** statement is alternative to using multiple **else if** conditions

```cpp
int day = 2;
switch(day){
    case 1:
        std::cout << "Monday\n";
        break;
    case 2:
        std::cout << "Tuesday\n";
        break;
    case 3:
        std::cout << "Wednesday\n";
        break;
    case 4:
        std::cout << "Thursday\n";
        break;
    case 5:
        std::cout << "Friday\n";
        break;
    case 6:
        std::cout << "Saturday\n";
        break;
    case 7:
        std::cout << "Sunday\n";
        break;
    default:
        std::cout << "Invalid day\n";
}
```
**case statements:** Each **case** checks whether expression matches the value.

**The break statement:** The **break** ensures that once a case is executed the switch statement is terminated so the next case below don't not get reached 

**default case:** The **default** case executes if no other case matches the value of the expression

### Loops: for, while, do-while

These are used for repating a block of code, based on a certain condition or until a condition is met.

#### The 'for' loop

This is used oftenly when the number of iterations are known beforehand.

**Example**

```cpp
for (int i = 0; i < 5; ++i){
    std::cout << "Iteration: " << 1 << "\n";
}
```

**Syntax**

```cpp
for (initialization; condition; increment/decrement){
    // Code to execute in each iteration
}
```

- **Initialization:** Executed once before the loop start, used to setup loop counter.

- **Condition:** Tested before each iteration. If the conditions evals to **true**, the loop body executes

- **Increment/Decrement:** After each iteration, the loop variable that was intialized at the begin as the loop counter is updated.

**Use case:** The ```for``` loop is ideal for when you have the exact number or a fixed number iterations that are known

#### The 'while' loop

The ```while``` loop is used when the number of iterations are not known so the loop continues as long as the specified condition evals to true

**Example:**

```cpp
int i = 0;
while (i < 5){
    std::cout << "Iteration: " << 1 << "\n";
    ++i;
}
```

**Syntax:**

```cpp
while (condition){
    // Code to exec as long as the condition is true
}
```

- **Condition:** The **loop** tests the condition before each iteration. If the condition evals to true the loop continue and exec, else if the condition evals

- **Use Case:** The **while** loops is useful when I do not know the amount of iterations required 


#### The 'do-while' loop

The ```do-while``` loop is similar to the ```while``` loop but the difference is that the this one ensure that the code block executes at least once regardless of the condition intially. The condition is tested after

**Example**

```cpp
int i = 0;
do {
    std::cout << "Iteration: " << i << "\n";
    ++i;
} while (i < 5);
```

**Syntax**

```cpp
do {
    // Code to exec
} while (condition);
```

- **Condition:** The loop condition is evaluated after the code block has executed at least once

- **Use Case:** The ```do-while``` is ideal when you need to perform an action before checking a conditon. E.g prompting a user then validating after

**Advanced Loop Concepts**

- **Breaking out of Loops:** The ```break``` statment can be used to exit instantly from a loop even if the conditions of the loop has not been met.

```cpp
for (int i = 0; i < 100; ++i){
    if (i == 10){
        break // This would terminate the loop
    }

    // Code exec
}
```

- **Skipping Iteration:** The ```continue``` statement skips the current iteration to move to the next

```cpp
for (int i = 0; i < 10; ++i){
    if (i == 5){
        continue;
    }

    // Code exec
}
```
